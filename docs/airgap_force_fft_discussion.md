# アウターロータPMモータのトルクリプル・電磁加振力・UMP評価に関する検討メモ

## 1. 対象と目的

サービスロボット等で使用される
多極・多スロット・集中巻のアウターロータ PM モータを対象とする。

具体的な検討対象として、
電気学会「電磁界解析用 公開モータ情報」の
多極多スロットアウターロータ形 PM モータ "GL80" を想定する。

GL80 は公開情報上、

- 42 極
- 36 スロット
- 3 相
- 集中巻
- 表面磁石型
- アウターロータ

のモータであり、
小形・軽量化が要求されるドローンやロボット用モータを
ターゲットとした公開モデルである。

---

## 2. ロボット用モータで重要と考えている性能

ロボット関節用モータでは、
一定速度で連続運転するだけではなく、

- 停止
- 保持トルク
- 低速運転
- 正逆転
- 急加速・急減速
- 瞬間的な高トルク

が頻繁に発生する。

したがって評価項目として、

1. 高いピークトルク
2. 高いトルク密度
3. 低コギングトルク
4. 低トルクリプル
5. 低電磁加振力
6. 軸受・シャフトに作用する非平衡電磁力
7. ケース・ロータ・ステータに作用する電磁応力

を考える必要がある。

特に低コギングトルクは、
低速時の滑らかさや位置決め性能、
減速機を含む関節系のバックラッシュ影響低減と関連して重要と考えている。

---

## 3. トルクリプルと振動は同一ではない

トルクは主としてギャップ上の接線方向 Maxwell 応力を
周方向に積分した量である。

一方、
モータ構造を励振する主因の一つは径方向 Maxwell 応力である。

したがって、

```text
低トルクリプル
```

であっても、

```text
低径方向電磁加振力
```

とは限らない。

これは集中巻モータを評価する際に重要である。

集中巻では、
コギングトルクやトルクリプルを低く設計できる一方、
巻線 MMF の空間高調波によって
低空間次数の径方向電磁力が生じる可能性がある。

---

## 4. ギャップ Maxwell 応力

ギャップ磁束密度を

```text
Br(theta,t)
Btheta(theta,t)
```

とする。

空気中の Maxwell 応力は近似的に

```text
Fr = sigma_r
   = (Br^2 - Btheta^2) / (2 mu0)

Ftheta = sigma_theta
       = Br * Btheta / mu0
```

で評価する。

厳密には `Fr`, `Ftheta` はこの段階では
力 [N] ではなく応力 [Pa] であるため、
実装では

```text
sigma_r
sigma_t
```

と呼ぶことが望ましい。

---

## 5. 空間次数の物理的意味

径方向応力を

```text
sigma_r(theta,t)
 =
sum_m P_m(t) cos(m theta + phi_m)
```

のように展開して考える。

### m = 0

全周に一様な径方向圧力。

主として平均的な膨張・収縮方向の荷重。

### m = 1

一方向に偏った径方向力。

全周積分しても合力が残る。

これは UMP (Unbalanced Magnetic Pull) と関係する。

軸・軸受への横荷重を考える場合に
特に重要な成分。

### m = 2

楕円状の変形を生じさせる電磁加振力。

全周の合力はゼロでも、
ケース・ステータ・ロータの変形や振動を励起できる。

### m >= 3

より高次の円環変形モードを励起する。

---

## 6. トルクとの関係

接線方向応力を全周積分するとトルクになる。

```text
T(t)
 =
R^2 L integral sigma_t(theta,t) dtheta
```

したがって、
2D FFT の観点では

```text
sigma_t の空間 m=0 成分
```

がトルクに直接対応する。

一方、

```text
sigma_r の m=1
```

は UMP と対応する。

このため、

```text
Ftheta と Fr を別実装にする必要はなく、
同じ空間 FFT / 2D FFT 基盤で処理できる。
```

---

## 7. UMP と軸受・シャフトへの影響

理想的に完全対称なモータでは、
径方向応力が大きくても
周方向に対称であれば径方向合力はゼロになる。

しかし、

- ロータ偏心
- 軸受クリアランス
- ロータ真円度
- ステータ真円度
- 磁石位置ずれ
- 磁石磁化ばらつき
- 組立公差

があると空間 m=1 成分が生じ、
正味の径方向電磁力が発生する可能性がある。

この力は

```text
Fx
Fy
UMP = sqrt(Fx^2 + Fy^2)
```

として評価する。

ロボット用途では、
この力が必ずしも高周波振動として現れなくても、

- 停止時の静的横荷重
- 低速時の準静的荷重
- 正逆転時の荷重方向変化
- 高トルク保持時の軸受荷重

として作用する可能性がある。

そのため、
NVH だけでなく機械寿命・耐久性の観点からも評価候補とする。

---

## 8. 偏心と電磁力の連成

ギャップが狭い側では磁束密度が増加しやすく、
Maxwell 応力は磁束密度の二乗に依存する。

したがって、

```text
偏心
 -> 狭いギャップ側の磁束密度増加
 -> 電磁吸引力増加
 -> 軸・軸受変位
 -> 偏心増加
```

という磁気－構造連成が生じる可能性がある。

将来的には遠心力解析・構造解析と組み合わせて
この連成を評価することも考えられる。

---

## 9. まず電磁界解析だけで評価したい量

構造解析に進む前に、
ギャップ磁束密度から以下を評価する。

### 接線方向

- `sigma_t(theta,t)`
- トルク
- トルクリプル
- `sigma_t` の空間高調波
- `sigma_t` の 2D FFT

### 径方向

- `sigma_r(theta,t)`
- `Fx(t)`
- `Fy(t)`
- `UMP(t)`
- `m=1`
- `m=2`
- `m=3`
- その他支配的な低空間次数
- `sigma_r` の 2D FFT

---

## 10. 2D FFT の目的

ギャップ応力を

```text
theta x time
```

または

```text
theta x rotor angle
```

の二次元データとして扱う。

2D FFT により、

```text
spatial order m
        x
temporal frequency f
```

または

```text
spatial order m
        x
rotor order n
```

のマップを作る。

これにより、

- どの空間次数が大きいか
- どの周波数で回転しているか
- 進行波か後退波か
- 構造固有モードと重なる可能性があるか

を把握できる。

---

## 11. ロボット用途での注意

ロボットは必ずしも一定速度で運転しない。

したがって、
実運転波形に単純な全時間 FFT を適用すると
周波数成分が広がる可能性がある。

将来的には

- rotor angle domain resampling
- order tracking
- STFT
- windowed 2D FFT

を検討する。

一方、
モータ単体の電磁設計比較では、
一定速度または等ロータ角刻みの解析から始めることでよい。

---

## 12. 重要な評価指標

モータ形状最適化では、
従来の

```text
maximize torque
minimize cogging torque
minimize torque ripple
```

に加えて、

```text
minimize radial force m=1
minimize radial force m=2
minimize selected low-order force harmonics
```

を候補とする。

特に、

```text
m=1 : shaft / bearing load
m=2 : ovalization / vibration
```

を区別して扱う。

最終的には構造解析と接続し、

- ケース変位
- ステータ変位
- ロータ変位
- 振動加速度
- 軸受反力
- 応力

を目的関数・制約条件へ拡張する。

## 13. GL80 で想定する解析ケース

初期検討では以下を候補とする。

### Case 1: 無負荷

目的:

- PM とスロットによる径方向力
- コギングトルク
- 無負荷の空間高調波

### Case 2: 定格相当負荷

目的:

- 電機子反作用を含む `Fr`
- `Ftheta`
- torque ripple
- 低次径方向力

### Case 3: 高トルク / ピーク電流

目的:

- ロボット関節で重要な瞬間高トルク時の応力
- `m=1`
- `m=2`
- 歯部・ロータ部への電磁荷重

### Case 4: 偏心

例:

```text
e/g = 0
e/g = 0.05
e/g = 0.10
e/g = 0.20
```

目的:

- UMP 感度
- 偏心ロバスト性
- 軸受電磁荷重

### Case 5: 停止保持

複数のロータ位置について

```text
id
iq
rotor angle
```

を変化させる。

目的:

- 静的・準静的電磁横荷重
- 高トルク保持時のケース・軸受荷重

## 14. 周期対称モデルに関する注意

UMP を評価する場合は特に注意する。

周期対称セクタ解析結果を
単純に全周複製すると、
モデルに存在しない非対称性は生成されない。

したがって、

```text
真の m=1 UMP
```

を評価するには、

- 全周モデル
- 偏心を含むモデル
- 磁石位置ずれ等を含む非対称モデル

が必要になる場合がある。

これは 2D FFT 実装上ではなく
電磁界解析モデル側の要件である。

## 15. 今回実装する処理系の位置づけ

今回の Python 処理は、
モータ電磁界解析と構造・振動解析の間に置く。

```text
Motor FEM
  |
  | Br(theta, step)
  | Btheta(theta, step)
  v
Air-gap force postprocessor
  |
  | sigma_r
  | sigma_t
  | torque
  | Fx/Fy/UMP
  | 2D FFT
  | spatial force modes
  v
Structural / vibration analysis
```

まず独立した Python 後処理として実装し、
計算内容と評価指標を固めた後に
既存ツールや解析フローへの統合を検討する。
